# NPM IPv4/IPv6 分族成本验收

2026-10-12，npm-ip-family-pipeline / T5。本报告记录本机固定条件，不作为生产吞吐或数据库容量 SLA。

## 结论与测量边界

分族活动会话的实际表/索引堆占用下降，IPv4 地址参数和部分数据库物理占用下降。
拥有型结束快照实际堆和预算峰值增加，IPv6/混合 RSS 峰值没有同步下降；插件吞吐中位数下降。
混合分表的页、索引和 ClickHouse part/marks 开销可以抵消地址列节省；短 IPv6 文本也可能小于固定16字节。
验收记录实际收益与代价，保持三万会话保证和默认预算，没有承诺每项成本改善。

- 当前：工作区 T1～T5；旧对照：e577023668aaa6be184c843efc06ec8fb29b303d 的 git archive，位于 /tmp/npm-ip-family-t5/baseline。
- 旧代码只在隔离副本适配测量入口，共用主工作区第三方缓存，产品不加入旧 ABI/Schema 兼容路径。
- Linux/WSL2 x86_64，所有成本测量固定 taskset -c 2，串行，批量512。双方 CMake build type/CXX_FLAGS为空；实际生产编译命令含 -g、DNDEBUG，无 -O，不能外推 Release性能。
- 对象成本：每组30,000 UDP活动会话，纯IPv4、纯IPv6、50/50交错混合，短namespace=cost.packet、观察域7、不同端口；每组5个独立进程，共30次。
- 插件吞吐：真实NPI解码与NPM .so，96字节 Ethernet/TCP RST原始报文，512行×100次迭代，basic-only/basic+session各warm-up一次，每组5进程，共30次；每模式输入51,200包。
- 当前混合前台显式basic_ipv4输出25,600行，旧统一实体输出51,200行；双方处理全部输入、启用模块相同，出口契约不同，不声称出口完全相等。
- 存储：真实DatabasePlugin与托管consumer，六模块各4,096行，共24,576行/后端/样本；mixed每模块各族2,048行，batch512。nullable字段NULL，其余固定；两边全局ID/地址序列相同。
- 存储每组合一次，共24个有效进程。current mixed在新库重测四项，以替换首次序号不一致的样本。四后端均使用全新隔离库，不删除现有数据。

## 复现与证据

标准入口 cmake -B build src；cmake --build build -j6。
测量targets为benchmark_npm_family_cost、benchmark_npm_basic、benchmark_npm_family_storage。
固定CPU后分别执行cost的ipv4|ipv6|mixed参数、basic的512 100 ipv4|ipv6|mixed参数，storage的隔离options文件/backend/family参数。
必须先建全新隔离库，避免重复写入污染样本；options权限600，不输出凭据。当前normal/Sanitizer完整功能测试覆盖真实PCAP、过滤/标签/调度/下游；本报告吞吐/存储使用可重复合成样本。

原始证据/tmp/npm-ip-family-t5/：cost-*.log、cost-summary.json、throughput-*.log、throughput-summary.json、storage-runs.json、storage-summary.json、sqlite-pages-*.json、clickhouse-parts.json。
environment.json与benchmark-build-command.txt记录工具链/CPU/编译条件，final-audit.json记录源码/二进制SHA256和完整验收状态。
