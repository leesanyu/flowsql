# Feature：诊断证据、图表与报告（diagnosis-artifacts）

状态：`[ ]` 规划草案，未实施；优先级 P1；创建日期：2026-11-25；更新日期：2026-11-26。
所属 [诊断 Epic](epic-llm-skill-diagnosis.md)：F2；依赖 [F1](../archive/feat-agent-data-access.md) 的结果、来源与授权契约。

## 业务意图与 Non-Goals

让分析用户及普通程序把真实查询结果组织为可追溯的表格、图表和结论，并保存为源数据变化后仍可阅读的报告，
通过统一 HTTP/MCP 接口重读和导出 Markdown/PDF；这项能力不要求任何 Agent 服务运行。

- 不交付调查推理、聊天会话、探索工作区的通用持久化或 MCP Apps 宿主适配。
- 不复制整个数据库，不承诺跨多个数据库查询的一致快照；每项结果保留真实观测时间和范围。
- 不把重新执行 SQL 当作历史报告读取，不允许模型伪造数值、执行记录或原始来源。
- 不执行模型生成的任意 HTML/JavaScript，也不为每个客户端建立不同报告格式。

## 核心数据与接口契约

T1 在编码前冻结 JSON Schema/OpenAPI、证据保存/读取接口及授权边界；随后图表和导出使用同一数据定义。

| 数据 | 核心内容与保证 |
| --- | --- |
| `AnalysisContext` | 问题、来源引用、运行/快照身份、时间窗、筛选、字段及聚合口径，标明历史证据或新观测；有修订身份但不授予权限，执行范围仍由 F1 判定 |
| `Evidence` | 受信任 QueryResult 的持久副本、实际查询/参数、字段类型与说明依据、范围/完整性、观测时间和来源摘要 |
| `DisplayBlock` | 表格/图表/文字类型、数据与字段引用、单位/口径、证据引用；图表只引用已取得的数据和允许的渲染配置 |
| `Finding` | 已观察事实、候选原因、反证、证据缺口和后续验证建议；数值引用实际证据，不把自由文本置信度当校准概率 |
| `Report` | 主体、标题、上下文、内容块顺序、结论、证据集合、报告/保存修订身份及人工/模型修改来源；保存结果固定，更新校验预期修订，冲突不覆盖 |
| `Selection` | 证据/内容块及上下文修订、真实字段和值、系列、时间或范围边界；可保存为受主体权限约束的引用供 F3/F5 读取，不携带权限或自动执行查询 |
| `ArtifactOperation` | 保存/导出请求身份、参数摘要、目标报告修订、状态和结果引用；响应丢失后可查询/重试，导出文件有明确有效期 |

- 证据由服务端根据 F1 结果身份读取并保存；查询身份不是永久证据，原结果失效时明确失败，不以当前重查补造历史。
- 保存调用 F1 的受限租约/读取契约并校验摘要、类型与完整性；证据内容和索引成功提交后才返回可引用身份，失败释放租约并清理未提交临时内容。同主体同请求重试返回已保存证据，参数变化冲突；重试不能因原结果随后过期丢失已成功保存的记录。
- 结果快照包含图表实际使用的聚合或必要明细及说明，记录采样/截断；派生数据保留输入和确定性变换依据。
- 结构化数值声明必须引用证据单元格或已登记的确定性派生值，由程序核对字段、范围与值；不承诺自动证明任意自然语言。自由文字与人工编辑保留作者和来源，其因果解释与引用质量由 F3/F4 评测。
- 表格支持分页、排序、范围内筛选、单位和 NULL 展示；展示筛选与原证据范围分开，跨范围查询由 F1 产生新证据。
- 必需图形为折线、柱状/条形、饼图、直方图；同时支持声明场景使用的堆叠图、散点、箱线和热力图，并验证各自统计口径。
- 图形支持适用的悬浮、缩放、系列和范围选择，提供对应数据入口；表图文字必须引用同一证据，不再次独立计算产生另一套值。
- 图表声明选择对应的字段身份、时区、时间桶边界和分组值；Top-N 的“其他”等不能精确映射的集合不伪造源过滤条件，返回限制说明。共享组件输出同一 Selection，F3 负责宿主桥接，F5 负责探索上下文转换。
- 图表方案比较受约束的 Vega-Lite、既有 Graphic Walker 复用及 ECharts；最终渲染技术由真实图形、事件和导出验证决定。
- 交付独立可读的报告页面及可复用渲染组件；F3/F5 在其上集成交互，不能复制一套存储、报告模型或导出实现。
- 提供证据/报告保存、读取、列举及导出 HTTP/MCP 能力，复用 F1 的接入与授权；模型不可通过文档内容获得写入其他对象的权限。
- F2 交付产物工具在 F1 MCP 服务中的注册、Selection 保存/读取及静态图/授权阅读链接；F1 不依赖 F2，F3 再增加 Apps 资源。浏览器使用同一主体的认证入口，链接和对象 ID 本身不授予权限，静态图、附件及导出下载同样校验访问。
- 已保存证据/报告归属主体并具有独立产物权限，读取不要求源库仍在线；源访问与产物访问分别授权，不能凭源 ID 读取他人报告。本期不新增匿名分享或跨用户协作权限系统，分享通过获准导出完成。
- Markdown 完整离线包包含 `.md`、图片和必要附件；PDF 从同一报告结构生成，包含中文字体、分页、长表重复表头和清晰图形。
- 保存和导出均有字节/条数/执行预算；长表完整分页或在离线包中提供完整附件并标注摘要范围，不静默截断为“完整”。导出固定报告修订并提供状态查询/取消；超限、渲染失败和临时文件过期明确返回，不影响原报告。
- 产品数据进入可配置的持久存储；`evidence/` 仅用于开发验收缓存，不能成为报告运行依赖。
- T1 冻结存储配额、引用生命周期和失败清理：保存报告引用的证据不能被临时结果/导出 TTL 清理，配额不足明确拒绝新保存，重启不发布残缺记录。服务端沿用 C++ 插件框架，浏览器渲染/导出工具只消费受控内容，不直接访问源库或任意网络/宿主文件。

## 主链路

1. **生成产物**：普通客户端经 F1 得到结果 → F2 取得并保存真实证据 → 校验表图与文字引用 → 阅读并编辑报告 → 固定保存结果。
2. **重读与分享**：独立读取报告 → 从已保存证据渲染 → 导出 Markdown/PDF → 脱离 Agent、源数据库及在线资源离线阅读。

## 验收锚点与依赖

| 编号 | 必须转成可执行断言的结果 |
| --- | --- |
| A1 依据 | 证据由 F1 实际结果一致转存；伪造、越权、失效引用被拒绝；类型、摘要、观测时间、说明、采样和截断可重读，保存中断不留下可引用的半份证据 |
| A2 持久化 | 保存后修改/删除测试源数据、改变当前说明并重启服务，历史报告及数据不变；编辑冲突保留原稿，不覆盖原保存结果 |
| A3 表图 | 声明图形逐项对照固定数据，直方图频数/比率分母/分位数等可独立核对；NULL/空集/受限数据明确呈现 |
| A4 交互 | 浏览器真实点击/框选产生绑定证据/上下文修订的 Selection；保存/重读保持字段、分组与时间桶边界，“其他”集合不可精确映射时明确限制；展示不改写证据或隐式读取新范围 |
| A5 导出 | Markdown 包与 PDF 的中文、表头、分页、图形和证据引用完整；离线打开无需外部图片服务，数值与保存报告一致 |
| A6 独立性 | Agent 关闭时普通 HTTP/MCP 客户端仍可保存/重读/导出，独立报告页面仍可用；访问不能跨越授权产物范围 |
| A7 操作与配额 | 保存/导出响应丢失后同请求返回原操作，参数冲突拒绝；并发编辑不覆盖，导出固定修订；超限、取消和故障不损坏已存报告，未授权静态图/选区/附件下载被拒绝 |

- 以 F1 真实结果和固定数值 fixture 验证，不要求模型服务；图表/PDF 需要实际浏览器、字体和选定渲染依赖。
- F2 对结果契约的验证不默认重跑全部数据库后端；只有改动 F1 共享计算/来源契约时才纳入相关回归并说明依据。
- 构建目标、浏览器/导出用例、持久化 fixture 及支持图形在对应工作台冻结；不得删去用户要求的四类基础图形或任一种导出格式。
