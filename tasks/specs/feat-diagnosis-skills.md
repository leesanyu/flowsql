# Feature：外置 Agent 诊断与 Skills（diagnosis-skills）

状态：`[ ]` 规划草案，未实施；优先级 P1；创建日期：2026-11-25；更新日期：2026-11-26。
所属 [诊断 Epic](epic-llm-skill-diagnosis.md)：F3；依赖 [F1](../archive/feat-agent-data-access.md) 和 [F2](feat-diagnosis-artifacts.md)，不依赖专用 Agent 或产品工作台。

## 业务意图与 Non-Goals

让使用通用 Agent 的网络分析用户加载可复用诊断方法，通过 FlowSQL 标准工具完成异常调查，
在宿主或独立产物页面阅读表图与有证据的结论、继续追问并保存报告；同一方法和评测集供专用 Agent 复用。

- 不交付自己的 Agent 运行时或聊天工作台，不重建字段字典、MCP 数据服务、图表渲染和报告导出。
- 不承诺所有 MCP 宿主自动加载 Skills 或支持 MCP Apps，也不迁移外置宿主的私有会话状态。
- 不把安装成功、Schema 合法、Mock 通过或文字流畅作为真实诊断效果的验收。
- 不实现自动修复、无依据根因承诺或在线自动改写已发布 Skills。

## 核心数据与接口契约

T1 冻结技能包、输入输出、支持宿主与真实模型评测契约；核心数值和证据结构复用 F1/F2。

| 数据 | 核心内容与保证 |
| --- | --- |
| `SkillPackage` | Agent Skills 格式的说明、适用条件、调查步骤、反证/停止条件、工具依赖、引用和必要脚本/模板；可追溯发布身份 |
| `DiagnosisInput` | 用户问题与 F2 AnalysisContext，明确可用数据和调查范围；不携带数据库或模型私有凭证 |
| `DiagnosisOutput` | F2 表图/事实/候选原因/缺口/建议及证据引用，实际保存为统一产物 |
| `DiagnosisCase` | F1 数值 fixture 的来源/摘要与初始化依据、固定问题、独立预期事实/数值、反证、禁止归因、必需产物和预算；调试与验收输入分别标识 |
| `EvaluationRun` | 技能内容身份、宿主/模型/配置、实际工具轨迹、判定、延迟和成本；秘密不进入记录 |
| `HostCapabilities` | 实测宿主的 MCP、Skills、图片/链接和 MCP Apps 能力；功能支持与未验证项分别呈现 |

- Skills 按需加载领域方法，字段、单位、运行依据通过现有 describe/resolve 取得；不复制一套 DNS 字段真相。
- 首个真实包覆盖 DNS 时延、响应结果和观察缺口调查，包含时间/方向/有效性、RCODE、query_only、重试及运行/视图去重限制。
- T1 复用 F1 已声明计算及真实 fixture，补齐正常对照、时延升高、非零 RCODE、query_only/观察不足、跨运行重复及反证场景；数据初始化/清理用统一配置的隔离资源，说明缺失按缺口报告，不由 Skill 补造来源事实。
- 展示方法包含趋势、排序贡献、占比与分布选择；分母、Top-N、采样、缺失/零值明确；不得凭模型自行生成数值或概率。
- 包固定所需工具/Schema、最低指标和发布内容摘要，F4 直接复用；如需新增计算先回到 F1 更新契约和断言。脚本仅封装获准工具或处理已授权的有限结果，声明依赖，不借宿主 Shell 直连数据库或绕过权限。
- Prompt 传递角色、问题与输出要求；服务端工具执行权限。数据行或说明中的指令不得扩大调查权限。
- 普通 MCP 宿主取得结构化结果、静态图与 F2 可交互产物链接；MCP Apps 宿主复用 F2 组件在对话内呈现和传回选区。
- 普通宿主的独立产物页不自动控制外部会话：用户选择后由 F2 保存 Selection 引用，页面提供可复制的追问文本，宿主经产物工具读取该引用并继续；需真实验证此回传，不要求用户手填字段或内部身份。
- Apps 适配由 F3 交付工具 UI 元数据、`ui://` 资源及宿主桥接，并注册到 F1 MCP 服务；渲染与 Selection 存取仍属于 F2。按[官方 Apps 契约](https://modelcontextprotocol.io/extensions/apps/overview)核验实际宿主的资源加载、认证、选择消息和上下文更新，不把普通网页链接当作已完成内嵌适配。
- 至少验收一个真实通用 Agent 的标准工具/Skills 路径，以及一个真实支持 MCP Apps 的宿主的内嵌交互路径；可以为同一宿主的明确能力模式。
- 宿主的图形选择更新明确的诊断上下文，依 F1 重新验证范围；不把跨域网页地址或图片文本当作授权上下文。
- F1 只约束 FlowSQL 工具入口，不能控制外部宿主所有本地工具或强制其取消模型；接入说明必须区分宿主停止与 F1 任务取消，并提供实际任务状态/取消入口。资料按 [Agent Skills 规范](https://agentskills.io/specification)打包，宿主私有权限机制不当作服务端授权。
- 真实模型评测固定数据集、重复次数、预算及判定阈值后执行；关键数值/引用/权限和明确禁止归因使用确定性断言，语义质量另有可复核评判。
- 模型裁判可以辅助评测，不得作为唯一正确性依据；失败、未执行和环境缺失均单列，不能计入通过。
- T1 冻结场景、模型/宿主版本、重复次数、硬性断言与语义评分门槛、总费用和停止预算；关键数值/引用、越权及禁止归因的硬性失败不能被平均分抵消。运行前核验真实宿主/凭证可用，T4 按冻结清单逐项核对，不临时以另一个宿主代替缺失能力。

## 主链路

1. **标准宿主**：配置 MCP 与 Skills → 提问 → 发现/描述 → 查询并验证候选解释 → F2 保存表图及结论 → 打开产物追问 → 保存/导出报告。
2. **图形宿主**：同一调查取得证据 → MCP Apps 展示 F2 图表 → 用户选中对象或范围 → Agent 获取结构化选择并继续验证 → 更新报告。

## Feature Tasks

- [ ] **T1：交付可分发的 DNS 诊断方法及有独立预期的评测集，使不同 Agent 对同一业务问题遵循一致的数据语义和证据标准。**
  验收 A1 的包/格式及 A2 的 fixture/断言准备；冻结真实宿主可用性、模型、工具/指标清单、重复次数及阈值，交付可供 F4 直接复用的技能与评测输入；真实加载和模型效果由 T2～T4 验收，不在看到成绩后放宽条件。
- [ ] **T2：交付真实通用 Agent 的完整调查闭环，使用户无需专用 Agent 也能取得有依据的表图结论和可保存报告。**
  验收 A1/A2/A3/A5 及 A4 的标准页面回传部分，复用 F1/F2 能力；验证真实加载、表图、复制选区追问和报告导出。
- [ ] **T3：交付 MCP Apps 内嵌图形及选择追问，使支持的外置宿主可在原对话中继续调查异常对象和时间范围。**
  验收 A4/A5；普通宿主的产物链接路径同时保持可用，能力差异明确可见。
- [ ] **T4：交付可重复的真实模型评测和接入说明，使诊断包的效果、成本及宿主支持范围可核查并供内置 Agent 复用。**
  验收 A1～A6；不以某次成功回答替代冻结数据集和重复运行。

## 验收锚点与依赖

| 编号 | 必须转成可执行断言或固定评判的结果 |
| --- | --- |
| A1 包与加载 | Skills 格式、资源引用和真实宿主加载通过；方法读取既有说明，不使用手抄字段替代真实契约 |
| A2 DNS | 真实结果覆盖时延有效/无效、matched 与非零 RCODE、query_only、观察不足、跨运行和重复视图；应识别反证，不能错误确定根因 |
| A3 产物 | 输出实际表格及恰当图形，数值/结论引用真实证据，用户能保存并下载 Markdown/PDF；未执行查询不伪造结果 |
| A4 图形追问 | 普通宿主完成 F2 页面选区→复制追问→工具读取选区→继续；Apps 宿主在对话内完成同等链路，字段/时间桶/范围准确；不支持 Apps 的模式提供页面路径，但不能替代必需的真实 Apps 验收 |
| A5 权限与错误 | 注入式数据、越权范围、工具失败、空集和预算耗尽不导致扩大权限或编造结论；保留已得证据及缺口 |
| A6 效果 | 冻结场景及重复运行清单完整执行，数值/引用/越权/禁止归因硬断言全通过且语义评分达标；列出调用次数、延迟和实际或明确标注估算的成本，未知成本不写成零；失败/跳过不计通过 |

- 模型凭证、宿主配置与数据依赖在实施工作台声明；私有配置不入库、不上命令行或日志；具体供应商及支持范围由真实可用环境确定。
- F3 必须运行真实模型和真实宿主，Mock 仅用于契约/错误路径；依赖不可用时记录阻塞，不能降格为仅文档验收。
- 评测程序和业务断言随实现入库，运行日志/样本放 `evidence/diagnosis-skills/`；不建设跨产品通用评测平台。
