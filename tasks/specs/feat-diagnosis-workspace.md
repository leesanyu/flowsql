# Feature：交互诊断工作台与探索联动（diagnosis-workspace）

状态：`[ ]` 规划草案，未实施；优先级 P1；创建日期：2026-11-25；更新日期：2026-11-26。
所属 [诊断 Epic](epic-llm-skill-diagnosis.md)：F5；依赖 [F1](../archive/feat-agent-data-access.md)、[F2](feat-diagnosis-artifacts.md)、[F4](feat-diagnosis-agent.md) 及现有探索页面。

## 业务意图与 Non-Goals

让用户从独立诊断页面或数据探索当前对象/选区进入同一调查会话，连续阅读、选择和追问表格/图表，
核对事实与候选原因，编辑并保存诊断报告；无需复制 SQL、内部身份或截图来解释当前问题。

- 不再建设 Agent 运行时、证据存储、图表引擎或报告导出；复用 F1/F2/F4。
- 不实现通用探索方案跨重启持久化、任意仪表盘平台或外置宿主私有对话迁移。
- 不把聊天文本中的链接/字段名当作可信来源身份，不从截图猜测当前筛选或范围。
- 不扩大诊断域至新协议、原始报文回溯或自动修复；不以仅增加聊天输入框完成验收。

## 核心数据与接口契约

T1 在编码前冻结入口/路由、上下文交接、浏览器消息和组件事件契约，复用 F2/F4 的数据定义。

| 数据 | 核心内容与保证 |
| --- | --- |
| `ExplorationHandoff` | 来源/结构/运行/快照身份，时间、筛选、字段、聚合、图表、受信任结果/说明引用和选区；包含上下文修订及历史证据/新观测标记，浏览器行数据不能作为可信结果 |
| `WorkspaceState` | F4 会话/运行身份、事件游标、当前上下文修订、选中的 F2 证据/表图及待提交输入；不建立另一份服务端事实 |
| `Selection` | 复用 F2 的对象、系列、时间或范围选择，转换为可显示的追问上下文，再交由 F1/F4 验证执行 |
| `ReportEdit` | 用户选择的 F2 内容块、顺序、结论/备注及编辑依据；保存形成固定结果，不改写历史证据 |

- 独立页面可从问题和来源开始，查看会话与报告；探索页提供“诊断当前数据”和图表选区入口，可从面板展开为完整工作台。
- 双入口共用同一会话接口和身份；导航、展开或返回不得悄悄创建另一份调查、改变来源或丢失筛选。
- 会话列表/历史从 F4 获取，报告列表/修订从 F2 获取；刷新或断线按事件游标续读，游标过期用服务端状态快照重新同步，迟到的旧运行/旧上下文事件不得覆盖当前画布。重复发送使用同一请求身份，遵守 F4 单会话单运行契约。
- 传递明确来源、时间、字段、聚合和选区，使用受控引用并由服务端验证；凭证不放 URL，跨窗口消息校验来源和发送方。
- 既有探索来源与 F1 NPM 公开关系统一定位；按实际需要补齐探索来源消费，不绕到内部表或仅靠相同名称关联。
- F1 负责公开来源及受控执行，F5 负责现有探索目录/界面使用这些来源和交接桥接。当前[探索服务](../../src/services/visualization/exploration_service.cpp)排除数据库视图，[嵌入组件](../../src/frontend/src/components/ExplorationFrame.vue)只交接展示环境；不能把这两项接入工作当作已有能力。
- 探索结果只有经服务端核验的 F1 ResultRef 或 F2 Evidence 才可直接进入证据链；其余仅作为查询上下文，经 F1 新查询生成结果，并标明这是新观测。DataFrame 快照若能验证身份且租约有效则复用，否则提示重新取样或仅阅读已存证据，不能静默替换成“最新”数据。
- 探索工作流转换仅支持 T1 冻结的字段/过滤/聚合和图形选区组合；不支持的表达式、派生字段或集合明确说明，保留原上下文，不忽略条件后继续执行。选区默认与当前过滤求交，时间桶边界/时区沿用 F2 Selection。
- “对话 + 证据画布”展示表图文字、进度、缺口和引用；用户可固定多个证据、查看数据/口径并选择对象追问。
- 表格排序筛选和图形缩放只改变展示；发起更大范围调查必须明确上下文变更，不覆盖原证据。
- 提示当前调查范围、正在执行的操作及失败/取消状态；错误、空集和信息不足可操作，不伪装成成功结论。
- 报告编辑/保存/下载调用 F2；独立工作台在 Agent 不可用时仍可阅读已保存产物，当前调查显示真实不可用状态。
- 报告编辑携带预期修订，冲突保留本地草稿并显示服务端版本；导出跟踪 F2 操作状态和文件有效期，下载失败不触发重新调查。
- 诊断证据可返回探索：由 F5 服务端适配调用 F2 受权读取接口，将有界只读数据集交给探索快照并保留证据来源；后续计算复用既有执行能力，产生带输入证据引用的新结果，不重查源库替换历史数据。该路径与返回原探索页面分别验收。
- 工作台可以独立访问与部署，也可在现有 Web 中嵌入；内置入口不改变 F4 的独立进程边界。
- 交付可独立构建/发布的静态工作台包及配置化 F1/F2/F4 地址、浏览器认证入口和受信任嵌入来源；独立部署无需现有 Web 外壳，内嵌方式复用同一包。F2 阅读/导出及 F4 调查故障分别呈现，不把任一局部故障伪装为全部数据丢失。
- F3 外置 Agent 仍有独立 MCP/产物路径；本 Feature 不要求外置用户改用 FlowSQL 聊天页面。

## 主链路

1. **独立入口**：选择来源/范围并提问 → F4 调查 → 证据画布呈现表图与事实 → 选择对象追问 → 编排结论与证据 → F2 保存和导出。
2. **探索往返**：打开已有图表并选择区域 → 校验来源/筛选/口径，必要时明确生成新观测 → 进入同一诊断会话 → 继续调查 → 返回原探索或打开证据快照继续探索 → 保存报告，历史证据保持原范围。

## 验收锚点与依赖

| 编号 | 必须转成可执行断言的结果 |
| --- | --- |
| A1 双入口 | 独立入口可新建调查，探索入口携带实际来源/时间/筛选/字段/聚合/图表与选区；展开和往返不丢会话 |
| A2 身份 | 同名对象、切换来源、过期快照和迟到响应不串用；公开 NPM 关系可交接，未受信任的页面结果不能保存为证据；不支持的工作流明确拒绝，重新查询标为新观测，伪造范围不能越权 |
| A3 呈现 | 实际表格和声明图形可见可读，数据/单位/范围与证据一致；事实、候选原因和缺口清晰，不能只有文字结论 |
| A4 追问 | 使用真实鼠标/键盘选中时间范围或对象后提问，后续查询及回答限定准确；展示筛选不改写原证据 |
| A5 报告 | 用户可固定表图、排序内容、编辑结论并保存，Markdown/PDF 均可下载打开；人工修改来源可追溯 |
| A6 故障 | 取消、断网、Agent 不可用和重启有真实状态；事件重放/重同步不重复表图或混入旧运行，编辑冲突保留草稿，旧报告可读且不重查源库 |
| A7 整体验收 | 独立静态包脱离现有 Web 外壳及内嵌部署各完成真实 DNS 调查；认证和地址配置可用；既有探索选表、绘图、说明、取消及导航受影响路径继续通过 |
| A8 返回探索 | 从 F2 已存证据打开只读探索快照，排序/筛选/绘图沿用准确类型和来源；源库离线仍可操作，新增计算保持输入证据引用且不改写原报告，回到原页面保持会话 |

- 使用真实浏览器、F1/F2/F4、统一配置及隔离 DNS 数据；UI 模拟用于交互边界，不能替代最终模型闭环。
- 浏览器验收包含可见布局、实际点击/框选、键盘、窄屏及错误恢复，不凭 DOM 存在或直接调用回调声称通过。
- 冻结实际部署方式、前端/C++ 受影响构建目标和筛选回归；不重跑无调用关系的模块、协议和后端矩阵。
