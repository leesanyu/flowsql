# Feature：统一说明 JSON 阅读窗口

- 标识：`data-semantics-json-reading`；状态：2026-11-24 完成 T1～T3 并归档。

## 业务意图与 Non-Goals

工作台 DESC、结果列与探索字段/图表的使用者可在独立弹框阅读完整 JSON，避免大量“未知”和属性列表挤占原页面。
状态、结构、实体属性、字段说明、错误和本次精确依据统一封装，支持语法高亮、复制、下载和最大化。
不修改后端、HTTP、存储或推导规则，不重做管理编辑页，不引入富文本 HTML 执行或新依赖。

## 数据与交互契约

- `channelReading(observation)` 输出 `{reading, observation, entity_semantics}`：原始观察不变，待加载/缺失提示和全部实体属性（含未知）进入 JSON。
- `resultReading(context,indexes?,labels?)` 输出 `{reading, semantic_context}`：按真实输出位置选择字段，保留来源、错误、操作、单位及捕获依据。
- JSON 使用既有无损整数序列化；token 仅以文本节点呈现，不解析说明中的 HTML。算子 DESC 统一展示观察结果，完整契约沿精确引用显式读取。
- 工作台 DESC 完成后自动打开阅读窗口；结果/历史列与探索入口按需打开。每页同时一个模态窗口，支持关闭/Esc/焦点返回、最大化、复制和下载。
- 打开/关闭/复制不请求业务数据、不保存、不重新计算；读取精确版本仍为显式动作。新执行/切源关闭旧窗口，迟到的读取不覆盖新对象。
- 探索内嵌/独立同一窗口；当前对象导航沿用已验证的 Web origin，不将任意地址传给上游。

## 主链路

1. DESC/结果字段入口 → 已捕获对象或上下文 → 纯数据投影 → 统一 JSON 模态阅读窗口。
2. 探索来源/所选字段/图表入口 → 当前来源或快照/计算依据 → 相同窗口；关闭后返回原图表和焦点。
